COMPONENT INSPECTOR Networking & TLS

MetalLB + Traefik Ingress & Cert-Manager

MetalLB provides bare-metal LoadBalancer IPs inside the Proxmox cluster, handing traffic off to Traefik as a cloud-native reverse proxy. Cert-Manager automates Let's Encrypt TLS certificates with zero manual renewal overhead.

Enterprise & Security Value

Enforces strict TLS termination, security headers, and isolated routing rules across Nextcloud, Talk HPB, and Keycloak.

Self-Hoster / Architect Note

Using Traefik IngressRoutes makes sticky sessions and WebSocket upgrades for Nextcloud Talk reliable out of the box.

01 // ORCHESTRATION

Why Kubernetes Over Single-Host Docker?

A serious collaboration platform (storage, caching, signaling, AV, IAM) cannot rely on a single point of failure. Kubernetes delivers self-healing, modular isolation, and rolling updates without downtime.

02 // STATEFUL SAFETY

Database Outside the Cluster

Running MariaDB on a dedicated Proxmox VM outside Kubernetes makes stateful lifecycle management rock-solid-enabling instant hypervisor snapshots and isolated firewall rules.

03 // REPRODUCIBILITY

Declarative GitOps via ArgoCD

Zero manual changes in production. Every manifest and Helm release lives in private Bitbucket repositories; ArgoCD continuously reconciles cluster state with Git.

04 // REAL-TIME COMMS

Talk + High Performance Backend

Offloading WebRTC media streams to a dedicated Spreed Signaling HPB keeps video conferences crisp for teams while protecting core Nextcloud web workers from CPU spikes.
